## 检查内容

- PowerShell/CMD 与直接程序运行，成功/失败退出码，真实交互执行而非仅回显。
- Ctrl+A D、重连、接管、stuff、Ctrl+C、中文/空格路径、原生启动器回车参数。
- 关闭父进程/CMD 后持续输出，允许/禁止 breakaway 的父 Job，结束本会话子进程树。
- 面板重启与 worker 独立，认证/Host/CSRF、异常输入、日志下载、归档、重跑。
- Python 编译、前端 JavaScript 语法、依赖一致性、第三方许可、发布白名单与 ZIP 校验。
- 全新隔离目录安装：独立运行环境和原生启动器；实际后台命令成功退出并保存输出。
- 浏览器验收：版本显示、历史日志与禁用按钮、命令帮助、命令模式切换、必填校验、搜索空结果；本次浏览器警告/错误记录为空。命令执行、输入协议和会话控制以自动测试为证据，不能把页面浏览等同于完整人工交互测试。
- OSV 查询 pywinpty 2.0.15、@xterm/xterm 5.5.0、@xterm/addon-fit 0.10.0：该次结果无匹配漏洞公告。这是数据库查询快照，不是零漏洞证明。
